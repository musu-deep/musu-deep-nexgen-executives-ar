# أوضاع مصادر البيانات

تدعم لوحة القيادة التنفيذية والموجز التنفيذي اليومي ثلاثة أوضاع لمصدر البيانات:

- `auto`: الوضع الافتراضي. يحاول قراءة بيانات المشروعات والمهام الفعلية، وينتقل إلى بيانات العرض التجريبي عند تعذر المصدر الأساسي.
- `live`: يستخدم البيانات الفعلية فقط، ويعرض حالة عدم الاتصال إذا لم تتوفر واجهات المشروعات والمهام.
- `demo`: يستخدم بيانات محاكاة تشغيلية ثابتة البنية ومتجددة التواريخ لأغراض العرض والاختبار.

## الضبط في Vercel أو ملف البيئة

```env
VITE_DATA_MODE=auto
VITE_BACKEND_URL=https://your-backend.example.com
```

يمكن للمستخدم المخوّل تبديل الوضع من قائمة **مصدر البيانات** داخل لوحة القيادة أو الموجز اليومي. يُحفظ الاختيار في `localStorage` للمتصفح الحالي.

> بيانات `demo` محاكاة وليست سجلات تشغيلية فعلية، ويظهر تنبيه واضح داخل الواجهة عند استخدامها مباشرة أو عبر التحويل التلقائي.
